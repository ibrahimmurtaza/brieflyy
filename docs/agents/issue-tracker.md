# GitHub Issue Tracker

This repo uses GitHub Issues for tracking work.

## Configuration

- Issues are created with `gh issue create`
- Comments are added with `gh issue comment create`
- Labels can be assigned and managed via GitHub's web interface or CLI

## PRs as a request surface

External pull requests are NOT automatically tracked in the triage queue. This means PRs from forks or outside contributors will not appear in the issue tracking system unless explicitly converted to issues.

The "PRs as a request surface" flag is currently **off**. If you want external PRs to be automatically tracked as issues, set this to **on** in the future.
