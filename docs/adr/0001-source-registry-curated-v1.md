# Source registry is fixed and curated in v1

In v1, Sources are added to Brieflyy's registry by the team only; Users cannot self-serve submit RSS feeds or arbitrary URLs. This is a deliberate scope choice to avoid a moderation and abuse surface area while the core ingest–cluster–summarize loop is being validated, and to keep the source-filter UX inside Topics free of mixed-quality inputs. Self-serve source submission is a planned v2 capability.
